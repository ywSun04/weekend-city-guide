# 周末探城

按天气、预算、同行人数，把一座城里的展览 / 市集 / 演出 / 徒步收成**能立刻出发的周末计划**。  
不是活动信息流：筛到的必须真的符合条件，页面上要写清「为什么推给你」和「现在能不能走」。

**在线演示：** [https://ywsun04.github.io/weekend-city-guide/](https://ywsun04.github.io/weekend-city-guide/)

手机打开即可点完全流程。活动、余票、通勤是演示数据，真实出行请以场馆为准。

## 产品判断

1. **推荐说到做到**  
   主推 3 个 + 备选 2 个。每张卡写符合两人同行 / 票价 / 室内避雨 / 市中心出发约 xx 分钟。不适配的不硬塞进清单。
2. **先回答能不能出发**  
   日期、建议到场时间、通勤估算、是否预约、票务预算，以及一个主按钮（高德导航）。地图用静态路线卡，避免空白加载。
3. **组队表述诚实**  
   小队保存在本机，跨设备加入需要后端。页面按演示模式处理，不假装已经做成社交产品。

## 页面

| 页面 | 做什么 |
| --- | --- |
| 首页 | 选城，开始规划 |
| 偏好 | 城市、预算、人数、兴趣、是否天气敏感 |
| 推荐 | 天气条 + 主推 / 备选；雨天优先室内 |
| 详情 | 票价、时长、集合点、路线卡 |
| 组队 | 创建 / 查看小队（本机演示） |
| 打卡 | 已去过列表 |
| 分享 | 生成可复制的周末攻略文案 |

示例城市：上海、杭州、北京。

## 本地打开

仓库是纯静态站，不需要构建：

```bash
# 任意静态服务器均可，例如
python -m http.server 8080
```

然后打开 `http://localhost:8080/`。直接双击 `index.html` 也可以看，部分浏览器对本地 `localStorage` 更严格。

## 技术

- `index.html` + `styles.css` + `app.js` + `data.js` + `product.js`
- 偏好、小队、打卡存在 `localStorage`
- GitHub Pages 发布，根目录即站点

适合作为本地生活 / 到店决策类产品的可交互原型。
